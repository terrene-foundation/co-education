# Learning Design for Education

Instructional design patterns, curriculum frameworks, assessment strategies, and gamification techniques for education across subject areas.

## Overview

This skill covers pedagogical approaches for teaching any subject:

- Bloom's taxonomy applied to learning objectives
- Curriculum design patterns and module sequencing
- Assessment types and rubric design
- Gamification strategies including simulations and competitions

## Reference Documentation

### Learning Frameworks

- **[blooms-taxonomy](blooms-taxonomy.md)** - Bloom's taxonomy applied to education: Remember, Understand, Apply, Analyze, Evaluate, Create. Concrete examples at each level for course topics.

### Curriculum Design

- **[curriculum-patterns](curriculum-patterns.md)** - Curriculum design patterns: spiral curriculum, mastery learning, project-based learning, case-study method. Concept-to-analysis progression and module sequencing.

### Assessment

- **[assessment-design](assessment-design.md)** - Assessment types: concept checks, calculation exercises, case studies, capstone projects, simulation exercises. Rubrics, difficulty calibration, formative vs summative.

### Engagement

- **[gamification](gamification.md)** - Gamification patterns: simulation competitions, scenario simulators, achievement badges, leaderboards, streak tracking, milestone celebrations. Implementation approaches.

## When to Use This Skill

Use this skill when:

- Designing an education course or module for any subject
- Writing learning objectives for course content
- Creating quizzes, exercises, or projects for learners
- Sequencing topics from beginner to advanced
- Adding game-like elements to learning platforms
- Evaluating learner progress and understanding
